## 📖 游戏简介

你是一名猎人，追踪猎物时误入密林深处的**古老祭坛**，惊醒了沉睡的梦魇。

作为惊扰它的代价，你被施加诅咒：**七天之内，献上一百个灵魂**。

梦魇赠予你猎枪与手电筒。丛林变异野兽、废墟墓园的丧尸、无形的鬼魂，全都是灵魂的来源。
七天期限将至，无论是否集齐灵魂，诅咒都会兑现。
当你真正集齐一百个灵魂站回祭坛，才将迎来最终抉择。

> 
> 游戏为纯前端网页游戏，HTML+CSS+JavaScript 实现，**无需安装客户端，浏览器直接打开即可游玩**。

## ⌨️ 操作说明

表格

| 按键 | 功能 |
| --- | --- |
| `W A S D` / 方向键 | 角色移动 |
| `Shift` | 奔跑，脱离敌人包围 |
| 鼠标移动 | 瞄准，枪口跟随鼠标准星 |
| 鼠标左键 | 射击，消耗弹匣弹药 |

| `R` | 装填弹药，弹匣容量 5 发 |
| `F` | 手电筒开关，消耗电池，照出伪装变异体与隐身鬼魂 |
| `E` | 互动：开箱、与梦魇对话、古堡传送、传送门返回 |
| `M` | 开关小地图 |
| `Esc` | 打开暂停菜单 |

## 👾 敌人一览

- **普通动物（危险度★）**：牛羊鹿猪，不会主动攻击，前期稳定灵魂来源；注意排查混在其中的变异体。
- **变异体（危险度★★★）**：伪装成普通动物，被照亮或攻击后狂暴扑杀；普通 / 灵弹均可击杀，掉落灵弹、电池。
- **丧尸（危险度★★）**：废墟、墓园大量出没，移动缓慢但数量庞大，注意不要被包围。
- **鬼魂（危险度★★★★）**：墓园、古堡出没，平时完全隐身，仅手电可见；**普通弹无效，必须使用灵弹**，可以穿墙。

> 
> ⚠️ 夜晚全地图怪物数量提升，攻击性增强，浓雾降低视野，非准备充分不要夜间外出。

## 🗺️ 地图区域

游戏为 **110×110** 大地图，出生点位于中央祭坛。

1. **祭坛空地（中央）**：复活点，与梦魇交互交付灵魂、触发结局，相对安全。
2. **原始丛林（北方）**：大量动物与变异体，主要灵魂产出地。
3. **荒废别墅 & 废墟（西北）**：丧尸、鬼魂巢穴，补给箱丰富，不建议夜间靠近。
4. **墓园（东北）**：高风险高收益，鬼魂密集，灵魂产出效率很高。
5. **随机古堡 ×3**：每局随机刷新，内部驻守丧尸 + 鬼魂，拥有普通宝箱与高价值金色宝箱；完成战斗后可通过青色传送门返回主世界。

## ⏱️ 时间系统

- 游戏内 1 天 = **90 秒**，完整总期限 **7 天（约 10.5 分钟）**
- 白天：视野开阔，怪物少，适合狩猎搜集物资
- 黄昏：天色变红，雾气加重，尽快撤退至安全区域
- 黑夜：浓雾笼罩，怪物大量增援，鬼魂四处游荡

> 
> HUD 顶部显示当前天数与时间进度，7 天倒计时归零直接触发失败结局。

## 💀 灵魂与补给机制

### 灵魂获取

击杀敌人灵魂会自动吸附到角色身上，无需手动拾取。

- 普通动物：灵魂 ×1
- 变异体 / 丧尸：灵魂 ×1，概率掉落物资
- 鬼魂：灵魂 ×2
- 古堡金色宝箱：灵魂结晶 ×6

> 
> **死亡惩罚**：角色死亡后在祭坛复活，但是损失当前持有灵魂的 **15%**，后期死亡代价极高。

### 补给箱

全地图一共 44 个补给箱（主世界 32 + 古堡内部 12），开启后不会刷新。
可开出：普通弹药、灵弹、电池、药草（恢复 40 生命值）。

## 🏁 三种结局

1. **结局 A｜献祭・世界末日**

> 
> 条件：集齐 100 灵魂，祭坛选择【献祭】
> 将全部灵魂交付梦魇，封印破除，梦魇吞噬整个世界，包括你。

2. **结局 B｜释放・世界和平**

> 
> 条件：集齐 100 灵魂，祭坛选择【释放】
> 释放全部灵魂，亡者得以安息，诅咒解除，你活着逃出森林。

3. **结局 C｜期限已至**

> 
> 条件：7 天结束没有凑齐 100 灵魂
> 诅咒生效，你化为梦魇的一部分，等待下一位闯入的猎人。

## 📝 速通推荐路线

1. **第 1 天白天**：熟悉操作，搜刮出生周边补给，向北进入丛林狩猎。
2. **第 1 天夜晚**：退回祭坛安全区休整，避免夜战。
3. **第 2‑3 天**：在丛林狩猎动物与变异体，稳妥攒下 25‑35 灵魂。
4. **第 4 天**：白天清理西北别墅废墟，刷丧尸，囤积灵弹与电池。
5. **第 5 天**：白天进攻墓园，手电常备，灵弹处理鬼魂，快速获取灵魂。
6. **第 6 天**：挑战古堡，获取大量灵魂结晶与补给。
7. **第 7 天**：补齐灵魂缺口，提前回到祭坛，不要拖到倒计时最后一刻。

## 💡 新手提示（新手十诫精简）

1. 灵弹留给鬼魂，对付普通生物尽量使用普通弹，节约珍贵灵弹。
2. 遇到动物群优先打开手电筒排查，避免误打伪装变异体。
3. 电池尽量维持一半以上余量，没有手电的夜晚极度危险。
4. 弹匣仅有 5 发，养成打几枪就找掩体装填的习惯。
5. 被追击时按住 Shift 边跑边打，不要原地硬扛。
6. 鬼魂可以穿墙，不要试图利用障碍物躲避。
7. 黄昏来临前规划撤退路线，不要贪恋战利品。
8. 攻打古堡务必备足灵弹、电池，保证血量与满弹匣。
9. 灵魂接近 100 时转为保守打法，死亡扣灵魂很容易功亏一篑。
10. 务必在第七天黄昏前抵达祭坛，选择权才属于你。
